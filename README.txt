SafeVision AI 시연용 프로토타입

실행 방법
1. ZIP 압축을 풉니다.
2. index.html을 Chrome 또는 Edge에서 엽니다.
3. OCR 기능은 Tesseract.js CDN과 한국어 언어 데이터 다운로드를 위해 인터넷 연결이 필요합니다.
4. 사진 업로드 후 '사진 OCR 및 점검 분석'을 누르면 OCR 결과가 표시됩니다.
5. 안전 위험요소 목록은 현재 시연용 가상 결과입니다. 실제 사진을 분석하는 비전 AI는 연결되어 있지 않습니다.
6. '보고서 출력 / PDF 저장'을 누르고 프린터 목록에서 'PDF로 저장'을 선택합니다.

파일
- index.html: 화면 구조
- style.css: 디자인 및 인쇄 스타일
- script.js: 이미지 업로드, OCR, 보고서 출력
